## 문제

- 재접속이 닉네임만 확인해서 낯선 사람이 남의 자리를 가져갈 수 있다(P1).
- 방 비밀값이 없다.
- 접속 폭주와 입력 규칙, 로그 개인정보도 막아야 한다.

## 목표

토큰으로 자리를 지키고, 폭주·부적절 입력·로그 개인정보를 막는다

## 작업

1. D5=A: 접속 때 서버가 재접속 토큰을 주고 브라우저가 저장한다. 같은 닉네임이라도 토큰이 다르면 「이미 쓰는 이름이에요」로 거절한다(T9).
2. 방 비밀값을 둔다: 비공개 방과 방 입장은 방 비밀값(토큰)을 확인한다.
3. 주소별 연결 제한: 1초 20번 연결하면 그 주소를 일정 시간 막는다. 터널 앞 헤더(CF-Connecting-IP)를 본다(T10).
4. 방 이름·닉네임 규칙: 빈 값, 13자 방 이름, 이모지, 금지어 거절 문구. 닉네임 8자는 그대로(T11).
5. 로그에는 방 코드, 이벤트, 오류만. IP는 앞 두 칸, 닉네임은 없음(T16).

## 완료 기준

- [ ] 다른 브라우저의 같은 닉네임이 거절되고 원래 브라우저는 자리로 돌아간다
- [ ] 폭주 20회/초에도 서버가 살아 있고 다른 주소의 방이 돈다
- [ ] 규칙 위반 입력이 이유 문구와 함께 거절된다
- [ ] grep으로 로그에 닉네임·전체 IP가 없다

- 방 비밀값이 없던 점(공개/비공개 구분 포함)을 여기서 닫는다.
