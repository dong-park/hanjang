## 문제

- 방을 만들고 목록에 올리고 정리하는 서비스가 없다.

## 목표

관리 서비스가 방 프로세스를 띄우고 목록·코드·한도·정리를 맡는다

## 작업

1. 별도 서비스를 만든다: 방 만들기(4자리 코드, 공유 링크), 방 목록 API(공개만), 코드 입장.
2. 방마다 헤드리스 Godot 프로세스를 띄우고 방별 포트나 경로로 wss를 이어 준다.
3. 공개 방 목록에 이름, 인원(2/4), 대기·판 중을 보이고 판 중 방은 입장 불가 표시를 낸다.
4. D4=A: 비공개는 목록에 없고 코드로만, 방 이름 12자까지, 동시 방 6개 한도(n1 숫자로 조정). 한도를 넘으면 「지금은 방이 가득 찼어요」.
5. 접속자 0명 방은 60초 뒤 프로세스를 끝내고 목록에서 지운다. 판 중 모두 나간 방도 같다.

## 완료 기준

- [ ] 방 만들기가 코드와 링크를 주고 링크가 같은 방에 간다
- [ ] 공개 방 2개가 목록에 뜨고 판 중 방은 입장 불가
- [ ] 비공개는 목록에 없고 틀린 코드는 「방을 못 찾았어요」
- [ ] 한도 초과 문구와 기존 방 무영향
- [ ] 빈 방 60초 뒤 프로세스 목록에서 사라진다
