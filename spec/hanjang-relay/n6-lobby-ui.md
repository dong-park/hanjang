## 문제

- 목록 API와 토큰이 있어도 폰에서 방을 만들고 고르는 화면이 없다.

## 목표

폰 웹에서 방을 만들고 목록에서 고르거나 코드로 들어간다

## 작업

1. 첫 화면에 방 만들기(이름, 공개 여부)와 방 목록, 코드 입력을 넣는다.
2. 방 만들기 뒤 4자리 코드와 공유 링크를 보인다.
3. 목록은 방 이름, 인원, 대기·판 중을 보이고 판 중은 입장 단추를 막는다.
4. 서버 재시작·방 없음·가득 참 문구를 첫 화면으로 돌려 보인다.
5. 토큰을 브라우저에 저장하고 재접속에 쓴다.

## 완료 기준

- [ ] 폰 에뮬레이션에서 만들기→링크 입장이 된다
- [ ] 목록과 코드 입장이 된다
- [ ] 실패 문구 캡처가 evidence 아래 있다
- [ ] 기존 웹 입장 화면이 깨지지 않는다
