## 문제

- 방 주인 폰이 잠기면 판이 끊기고, FIN 없는 끊김을 방장이 240초 동안 모른다.

## 목표

주인 폰이 잠겨도 판이 이어지고, 끊긴 접속을 20초 안에 안다

## 작업

1. D6=A: 주인이 끊기면 30초 기다리고, 돌아오면 자리로 복귀, 안 돌아오면 다음 사람에게 주인을 넘기고 문구를 보인다(T12).
2. Godot 웹소켓 서버의 ping 설정을 넣어 FIN 없는 끊김을 20초 안에 잡고 나머지 화면에 끊김 문구를 띄운다(T13).
3. 서버 로그에 감지 시각을 남긴다.

## 완료 기준

- [x] (헤드리스로 증명) 3명 판 중 주인 폰 잠금: 30초 안에 돌아오면 이어지고 안 돌아오면 승계 문구가 뜬다
- [x] (SIGSTOP 으로 증명) 와이파이를 끈 폰이 20초 안에 감지되고 서버 로그에 시각이 있다

## 구현 메모

- 기존 웹 웨이브에서 남은 문제: FIN 없는 끊김을 방장이 240초 동안 모른다. ping 간격과 타임아웃은 WebSocketMultiplayerPeer 설정으로 20초 아래로 맞춘다. 확인 안 된 것이므로 실제 값으로 잰다.
- 승계 규칙은 rules.gd를 건드리지 않고 session.gd 쪽에 둔다.
- 헤드리스 시험은 /tmp/hanjang-headless.lock을 잡고 하나씩 차례로 돌린다(동시 실행 금지).

- 보드 댓글 첨부 spec/**/evidence/*/cm-* 파일은 지우지 않는다.
- 결정 D1=C(방마다 헤드리스 Godot), D2=C(이 맥이 서버), D3=C(trycloudflare 임시 주소), D4~D8=A는 닫혔다.

## 진행 메모 (n5, 2026-10-16)

- 끊김 감지(T13): WebSocketMultiplayerPeer 에 ping 설정 인자가 없어 room.gd 에 앱 수준 ping을 넣었다. 서버(방 프로세스·LAN 방장)가 3초마다 _ping, 접속자가 _pong 으로 답하고, 12초 동안 응답이 없으면 서버가 그 접속을 끊고 「DROP_DETECTED t=<unix 초>」를 로그에 남긴다(닉네임 없음). 접속자도 서버 ping이 12초 안 오면 첫 화면으로 간다(「연결이 끊겼어요」). 최악 15초쯤이라 20초 안에 들어간다. 이전에는 240초.
- 주인 승계(T12): 판 중 주인이 끊기면 owner_grace(기본 30초) 동안 주인 자리를 비워 두고 기다린다(OWNER_GRACE_START). 같은 토큰으로 돌아오면(n4) 주인 자리 그대로(_set_owner → 접속자 OWNER_IS_ME). 안 돌아오면 판 중 나가지 않은 맨 앞 자리가 새 주인이 되고(OWNER_TRANSFER) 접속자에게 「○○님이 방 주인이 됐어요」(table_fx.owner_fx, Room.owner_changed). 주인이 한 번 정해지면 옛 주인이 돌아와도 되찾지 않는다. 대기실에서는 자리가 바로 비워져 기다림 없이 넘어간다. rules.gd 는 안 바꿨다.
- 시험 game/tests/test_drops.sh NET_DROPS_TEST_PASS: 판 1 접속자 프로세스를 SIGSTOP(FIN·응답 없음)으로 얼려 서버가 11~14초 만에 알고 나머지 둘에게 PLAYER_LEFT 가 간다. 판 2 --owner-grace=8 로 주인이 나갔다 돌아오면 OWNER_IS_ME 이고 OWNER_TRANSFER 없음. --owner-grace=4 로 안 돌아오면 OWNER_TRANSFER, 새 주인 OWNER_IS_ME, 나머지에게 OWNER_CHANGED, 이후 판이 이어짐. 판 3 기본값 대기 30.0초.
- 실제 폰 와이파이 끄기·화면 잠금은 사람이 n8 에서 본다. 헤드리스는 SIGSTOP 으로 같은 상황(FIN 없음, 응답 없음)을 만든 것이다. 승계 문구의 실제 화면 모습은 캡처하지 않았다.

## 확인할 것

- 실제 폰 2대 이상으로 판을 하다가 방 주인 폰의 화면을 잠그고, 30초 안에 다시 켜면 자리와 주인 권한(시작·다시 하기 버튼)이 그대로인가.
- 주인 폰을 30초 넘게 잠가 두면 나머지 화면 위쪽에 「○○님이 방 주인이 됐어요」가 뜨고 새 주인이 다시 하기를 누를 수 있는가.
- 폰 와이파이를 끄면 20초 안에 나머지 화면에 끊김 연출이 뜨는가.
- (헤드리스는 SIGSTOP 으로 위 상황의 서버·접속자 동작만 증명했다. 위 세 가지와 문구 모양은 실제 화면을 사람이 본다. n8 실폰 시험과 같이 봐도 된다.)
