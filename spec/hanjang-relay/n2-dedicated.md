## 문제

- 방 프로세스에는 방장 자리가 없는데 지금 코드는 방장이 판정을 돌린다.
- 맥 앱 LAN 방장 경로는 그대로 남겨야 한다(D7=A).

## 목표

방장 자리 없이 접속자만으로 방이 한 판을 끝내고, 맥 앱 LAN 방장도 그대로 돈다

## 작업

1. 헤드리스 전용 방 모드를 넣는다: 방 프로세스는 자리를 갖지 않고 판정만 한다.
2. session.gd/room.gd가 방장 자리 없이 대기실, 판, 결과를 돈다.
3. 접속자 2~4명 헤드리스 시험으로 한 판을 끝낸다(T3).
4. 맥 앱 LAN 방장 경로와 기존 시험 전부를 다시 돌린다(T14).

## 완료 기준

- [ ] 접속자 4명 한 판 시험이 종료 코드 0
- [ ] 남의 패 값이 접속자에게 가지 않는다
- [ ] 기존 헤드리스 시험 전부 종료 코드 0, 맥 앱 LAN 방장이 한 판 돈다
- [ ] 내 파일만 경로로 지정해 add한다

## 구현 메모

- 판정: game/net/session.gd, 규칙: game/rules/rules.gd. 규칙은 바꾸지 않는다.

- 헤드리스 시험은 /tmp/hanjang-headless.lock을 잡고 하나씩 차례로 돌린다(동시 실행 금지).
- 커밋은 파일을 지정해 add한다(git add -A·. 금지). push 하지 않는다.
