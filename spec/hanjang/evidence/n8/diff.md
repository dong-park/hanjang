# n8 스토리보드와 실제 화면의 다른 점

실제 창 캡처(4창 자동 한 판)와 스토리보드 frames를 나란히 보고 적은 목록이다. 비교 화면: compare.html. 같다/다르다의 최종 판단은 사람이 한다.
다 같은 것으로 보이는 것: 남색 점무늬 배경, 네모 칸 아바타, 갈무리 폰트 글자, 카드 두께와 그림자, 가운데 점선 고리와 방향 표시.

| 장면 | 다른 점 |
|---|---|
| 01 첫 화면 | 스토리보드는 닉네임 "나"를 입력한 상태. 실제는 빈 칸이고 "닉네임을 1~8자로 적어 주세요" 안내가 처음부터 보인다. 아바타 순서가 다르다(스토리보드 갈색·초록·파랑·분홍, 실제 파랑·초록·분홍·갈색). |
| 02 참가 | 스토리보드는 주소 칸에 입력 글자가 있고 "접속 중" 알림이 테두리 상자 안에 있다. 실제는 상자 없이 글자만 있다. 최근 방 칸이 실제는 버튼 모양이다. |
| 03 대기실 | 실제에는 왼쪽 위 "나가기" 버튼이 있다(스토리보드에 없음). 방장 창의 시작 버튼에 스토리보드의 반짝이는 테두리가 없다. 자리 4개가 모두 찬 상태라 "?" 빈 칸은 보이지 않는다. |
| 04 나눠 주기 | 스토리보드는 카드 여러 장이 사방으로 날아가는 중간. 실제는 한 장씩 날아가며 캡처 시점에 따라 장면이 다르다. 실제에는 방장 왕관과 오른쪽 아래 "뽑기" 버튼이 이미 보인다. |
| 05 내 차례 | 실제는 내 패 색이 스토리보드보다 어두운 톤이고, 더미 위 카드와 차례 시간 막대 위치가 다르다. 스토리보드의 "빨강 또는 7" 힌트 말풍선은 이 캡처에 없다. |
| 06 내가 냄 | 캡처 시점이 달라 실제는 건너뜀 도장·"반대로!" 문구가 같이 떠 있다. 스토리보드의 흐릿한 카드 잔상 한 장과 모양이 다르다. |
| 07 상대가 냄 | 실제는 상대가 낸 카드가 하늘 쪽에서 날아오는 순간이 아니라 이미 놓인 상태. 스토리보드는 위쪽 상대 카드가 중앙으로 날아오는 중이다. |
| 08 색 고르기 | 스토리보드는 뒤 화면 전체가 어둡게 덮이고 고른 색(초록)에 테두리가 있다. 실제는 어두운 덮개가 약하고 색 선택 테두리가 없다. 카드 숫자 글씨체가 실제는 두꺼운 픽셀 모양이다. |
| 09 공격 | 스토리보드는 "+2" 큰 글자가 내 패 위, 배너 문구는 "OO의 공격! N장 받아요". 실제는 +4 와일드 공격 캡처이고 배너가 "하늘의 공격! 체리 4장"으로 받는 사람 이름 방식이다. |
| 10 스킵·리버스 | 스토리보드는 "⇄ 반대로!" 문구에 화살표 기호가 붙고 건너뜀 도장이 왼쪽 사람에게. 실제 문구는 "반대로!"만 있고 기호가 없다. 카드 위 화살표 그림은 있다. |
| 11 뽑은 카드 | 스토리보드는 뒤 화면이 어둡고 6 카드 한 장이 크게 나온다. 실제는 +4 카드가 크게 나오고 뒤 화면이 어둡지 않다. 버튼 "바로 내기/가지기"는 같다. |
| 12 한장! | 스토리보드는 빨강 "한장!" 버튼 아래 시간 막대, 오른쪽 위에 "다른 사람 화면에서는 · 나: 1장 남음! · 잡았다!" 상자. 실제 한장! 버튼은 막대가 짧고, 잡았다! 상자는 제목 줄("다른 사람 화면에서는")이 없다. |
| 13 결과 | 스토리보드 제목은 "승리!"이고 줄마다 아바타와 오른쪽 "N장". 실제 제목은 "결과"이고 줄마다 "다 털었어요!"/"남은 카드 N장"이며 아바타 칸이 없다. 1등 줄 강조색은 같다. |
| 14 끊김 | 스토리보드 위쪽 알림은 주황 테두리, 실제는 빨강 테두리. "연결 끊김" 말풍선과 회색 아바타 자리는 같다. 알림 문구가 실제는 "카드 9장은 더미로"(그 사람 장수)다. |

## 이 캡처로 확인하지 못한 것

- 카드 날아가기·나눠 주기 같은 움직임은 정지 화면이라 길이와 느낌을 알 수 없다.
- 사람이 하는 창(수동으로 낼 카드를 고르고 한장!을 누르는 입력)은 이 근거에 없다. 네 창 모두 자동 플레이였다.
- 장면 12b 외침 알림, 12d 잡았다! 결과는 스토리보드 frames에 없는 장면이라 비교 대상이 없다.
