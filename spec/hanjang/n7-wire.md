## 문제

- 로컬 판 화면과 방장 세션은 아직 따로 돈다.
- 판이 끝나거나 누가 나가도 게임이 멈추면 안 된다.

## 목표

실제 방에서 장면 01부터 14까지 이어진다. 판 화면은 세션이 보낸 판 상태로 그려지고, 결과와 끊김이 처리된다.

## 작업

1. `game/screens/table_net.gd`: n4 세션이 보낸 판 상태를 `apply_snapshot`으로, `action_requested`를 세션 요청 RPC로 잇는다.
2. `game/main.gd` 화면 전환에 판 화면과 결과 화면을 더한다.
3. 장면 13 결과: 등수, 남은 장수, 다시 하기·대기실로. D9 추천대로 방장이 고르고 접속자에게는 방장을 기다려요.
4. 장면 14 끊김: 나간 사람 회색, 연결 끊김 말풍선, 카드가 더미로 돌아가는 연출, 위쪽 알림.

## 확인할 것

실제 창 두 개로 한 판을 끝까지 돌려 본다. 헤드리스 봇으로는 돌았지만 손으로 누르는 경로와 화면은 사람이 본다.

- [ ] `두창으로_테스트.command`로 한 판을 끝내면 결과 화면(장면 13)에 등수와 남은 장수가 뜨는가 (evidence/n7/13-result-host)
- [ ] 방장에게는 [다시 하기]·[대기실로], 접속자에게는 "방장을 기다려요"만 보이는가
- [ ] 다시 하기를 누르면 같은 둘이 나눠 주기부터 다시 시작하는가
- [ ] 결과에서 대기실로를 누르면 자리가 그대로인 대기실이 뜨는가
- [ ] 판 중에 접속자 창을 닫으면 그 아바타가 회색이 되고 말풍선·위쪽 알림·카드 날기가 보이며 남은 사람끼리 이어지는가 (evidence/n7/14-disconnect)
- [ ] 나눠 주기 길이만큼 첫 차례 시간이 늦게 시작되는 게 어색하지 않은가
- [ ] 상대 차례에는 내 패 전체가 어둡고, 내 차례가 되면 패가 밝아지며 낼 카드만 솟고 내 아바타가 빛나는가 (evidence/n7/fix-1, fix-2)
