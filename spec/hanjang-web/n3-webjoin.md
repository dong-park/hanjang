## 문제

- 새 전송 위에서 브라우저 참가가 아직 안 돈다.
- 접속 실패와 화면 꺼짐을 처리해야 한다.

## 목표

휴대폰이 맥 앱 방에 들어가 한 판을 끝낸다

## 작업

1. 웹 빌드가 D7 답대로 방장 주소를 정해 참가한다.
2. 꽉 참, 게임 중, 방 없음 문구를 앱과 같이 보인다.
3. 화면 꺼짐·탭 전환을 나간 사람으로 처리한다.
4. 맥 + 실제 휴대폰으로 한 판을 돈다.

## 완료 기준

- [ ] 맥 대기실에 휴대폰 자리가 생긴다
- [ ] 휴대폰이 남의 패 값을 갖지 않는다
- [ ] 세 실패 문구 캡처
- [ ] 앱 시험이 그대로 통과한다 (헤드리스 시험 종료 코드 0)
- [ ] 내 파일만 경로로 지정해 add한다

## 구현 메모

- (메인 추가, 웨이브 1 /review가 넘긴 것) 판 중 휴대폰 화면 잠금·앱 전환으로 웹소켓이 끊기면 같은 판에 다시 못 들어온다(room.gd _hello가 PLAYING이면 거절). 이 노드에서 같은 닉네임 재접속으로 자리를 되찾는 경로를 넣는다(최소: 끊긴 자리 유지 + 같은 닉네임 _hello 허용). 대기실 주소는 IP.get_local_addresses() 첫 사설 주소라 Docker/VPN이 있으면 틀릴 수 있으니 D7 자동 채움과 같이 점검한다. 사용자 지시로 자동화 진행 중이라 결정 행 없이 추천대로 넣는다.
