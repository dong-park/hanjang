## 문제

- ENet은 브라우저에서 못 연다.
- 앱도 같은 전송을 써야 같은 방에 들어간다.

## 목표

앱이 D1 답의 전송으로 방을 열고 참가한다

## 작업

1. D1, D2 답을 읽는다. 답이 없으면 추천대로 가고 구현 메모에 적는다.
2. `game/net/room.gd`의 방 열기·참가를 새 전송으로 바꾼다. 방 주소와 포트 규칙을 정한다.
3. 기존 헤드리스 시험과 두창·네창 시험을 새 전송으로 돌린다.
4. `main.gd`, `session.gd`는 다른 웨이브가 커밋한 뒤에만 열고, 필요한 최소만 고친다.

## 완료 기준

- [ ] 맥 창 2개에서 한 판이 끝난다
- [ ] 4인 헤드리스 시험이 통과한다
- [ ] 새 전송에서 맥 앱 서버가 열리는지 확인했다 (확인 안 된 것 해소)
- [ ] 앱 시험이 그대로 통과한다 (헤드리스 시험 종료 코드 0)
- [ ] 내 파일만 경로로 지정해 add한다
