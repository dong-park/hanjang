## 문제

- 화면과 입력이 마우스 가로 창 기준이다.
- 손가락, 세로, 화면 키보드가 아직 안 다뤄졌다.

## 목표

휴대폰에서 눌러서 낼 수 있게 한다

## 작업

1. D5 답대로 세로 안내를 만든다.
2. D6 답대로 카드 입력을 터치로 만든다.
3. 문지르기·확대·새로고침을 막는다.
4. D7 답대로 입력칸을 만들고 화면 키보드와 맞춘다.
5. 앱 마우스 동작은 바꾸지 않는다.

## 완료 기준

- [ ] 실제 휴대폰으로 카드 내기·되돌리기
- [ ] 세로 안내 캡처 2장
- [ ] 키보드가 입력칸을 가리지 않는다
- [ ] 앱 시험이 그대로 통과한다 (헤드리스 시험 종료 코드 0)
- [ ] 내 파일만 경로로 지정해 add한다
