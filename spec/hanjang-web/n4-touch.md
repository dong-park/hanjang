## 문제

- 화면과 입력이 마우스 가로 창 기준이다.
- 손가락, 세로, 화면 키보드가 아직 안 다뤄졌다.

## 목표

휴대폰에서 눌러서 낼 수 있게 한다

## 작업

1. D5 답대로 세로 안내를 만든다.
2. D6 답대로 카드 입력을 터치로 만든다.
3. 문지르기·확대·새로고침을 막는다.
4. D7 답대로 입력칸을 만들고 화면 키보드와 맞춘다.
5. 앱 마우스 동작은 바꾸지 않는다.

## 완료 기준

- [ ] 실제 휴대폰으로 카드 내기·되돌리기
- [x] 세로 안내 캡처 2장
- [x] 키보드가 입력칸을 가리지 않는다
- [x] 앱 시험이 그대로 통과한다 (헤드리스 시험 종료 코드 0)
- [x] 내 파일만 경로로 지정해 add한다

## 구현 메모

- 세로 안내(D5=A, T6): `game/export_presets.cfg`의 `html/head_include`에 CSS·스크립트를 넣었다. 터치 기기(pointer:coarse)가 세로이면 DOM 덮개 "가로로 돌려 주세요"가 뜨고, 돌리면 사라진다. 게임·접속은 DOM 덮개 밑에서 그대로 돈다. 에뮬레이션에서 세로→가로→세로로 바꿔도 같은 페이지(새로고침 없음)였다.
- 카드 내기(D6=A, T7): `game/ui/hand_view.gd`. 손가락(마우스로 바뀐 이벤트, device==DEVICE_ID_EMULATION)은 한 번 누르면 PICKED로 올라가고(청록 테두리), 같은 카드를 또 누르면 낸다. 다른 카드·낼 수 없는 카드·빈 곳을 누르면 내려간다. 위로 끌면 바로 낸다. 마우스는 한 번에 내는 기존 동작 그대로. 시험 `game/tests/test_touch.gd`(9항목 통과), 기존 `test_table.gd` 종료 코드 0.
- 문지르기·확대(T8): 같은 head_include에서 html/body를 fixed·overscroll-behavior:none·touch-action:none으로 두고 gesturestart·dblclick·contextmenu·touchmove(입력칸 제외)·350ms 안 두 번 touchend를 막는다. WebKit 에뮬레이션에서 CSS 값, 합성 이벤트 defaultPrevented, scrollTo 무반응을 확인했다.
- 키보드(D7=A, T9): `game/screens/title.gd`. 웹+터치 기기에서는 처음부터 입력칸·버튼을 위쪽(y 44~178)에 두고 로고·카드는 숨긴다. 칸을 누를 때 배치를 바꾸면 버튼이 손가락 밑에서 움직여 클릭을 놓치므로 고정 배치로 했다. 첫 화면에서 입력칸 자동 포커스는 휴대폰에서 뺐다. 데스크톱은 그대로.
- 근거(`evidence/n4-touch/`): 세로 안내, 가로 복귀, 휴대폰 배치 첫 화면, 키보드 자리 모사(회색 덮개는 화면 높이 절반을 가정한 모사일 뿐 실제 키보드가 아님), 실제 웹 빌드 `--local` 판에서 터치로 카드 올림·냄(콘솔 로그로 picked→play 확인).
- 못 한 것(미확인): 실제 휴대폰 조작, iOS Safari의 실제 화면 키보드·주소창 동작·한글 IME, 두 손가락 확대·당겨서 새로고침의 실제 제스처(합성 이벤트·CSS 확인까지만), 키보드 높이 가정. `join.gd`의 주소칸 자동 포커스는 n3의 미커밋 변경이 섞인 파일이라 건드리지 않았다.
- 시험 재현: `tools/export_web.sh` 후 서버 `python3 tools/serve_web.py 8064`, 판은 index.html의 `"args":[]`를 `["--","--local"]`로 바꿔 연다.

## 확인할 것

자동화로 WebKit 아이폰 에뮬레이션에서 세로 안내, 터치로 카드 올리기·내기, 휴대폰 배치 입력 화면을 확인했습니다. 실제 아이폰으로 `웹서버.command`가 보이는 주소를 열어 아래를 봐 주세요.

- [ ] 세로로 들면 "가로로 돌려 주세요"가 뜨고, 돌리면 사라져 게임이 이어진다
- [ ] 카드를 한 번 누르면 올라가고, 같은 카드를 또 누르면 나간다. 다른 카드나 빈 곳을 누르면 내려간다
- [ ] 판 중 화면을 끌거나 두 손가락으로 벌려도 확대·스크롤·새로고침이 없다
- [ ] 닉네임 칸을 누르면 키보드가 뜨고 입력칸과 방 만들기·참가하기 버튼이 가려지지 않는다. 8자를 치면 이름이 보인다
